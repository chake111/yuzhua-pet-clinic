# 愈爪在线演示落地页 · 说明

成稿是 `deploy/demo/index.html`。过程候选和方向卡在 `.oil-ui/demo-landing/`（仓库已忽略，不进 PR）。没有改应用代码。

## 视觉北极星

整页是一张已经取出的挂号单。第一眼是白纸和扒在纸沿上的团团，阅读从纸上的三行主诉开始，唯一的章是珊瑚色的「看演示」。

这句用来取舍：能印在这张纸上的留下，要另起一张功能卡的删掉。

方向从三个概念里选出（号源挂号单、前台柜台、候诊叫号）。叫号把团团写成患者，退回。前台并排三块屏幕会回到等权重截图，退回。假的排队号不进成稿，三秒要读到三端，不读一个没有出处的号码。

高级感在这里是：一张纸、一种字重对比（40/700 对 16）、纸外大留白、色相只有墨和一枚动作红。简洁是删掉首版那些等权重描边行，不是把字号磨小。

## 相对首版删掉了什么

- 三行带框、带箭头、权重相同的入口卡片。三端改成同一张纸上的三行栏位，左边是端，右边是账号。
- 首屏右侧的手机截图。截图挪到下一张纸，首屏只留纸、狗和字。
- 灰底圆角卡片、第二颗实心按钮、技术栈横条，以及六条工程说明。那些说明仍在仓库 README。
- 首屏里重复出现的重置说明只留纸的底栏和页脚各一次。

品牌感来自团团压住纸的上边线，以及整页只有一枚 `#d92549` 的章。`#ff385c` 只留在标志和项圈上，不铺底、不做标题。

团团这张 WebP 是 680×340，四周有透明留白。不透明像素大约在 (49, 68)–(630, 293)：肚子底边约在图高的 73.5%，最低的前爪约在 86.5%。`.dog` 若用 `translateY(-84%)`，图片盒子只有约 16% 叠进纸里，肚子其实还悬在纸沿上方，桌面的灰会从躯干和尾巴下面露出来。现稿用 `translateY(-70%)`：宽 320px 时肚子约贴进纸里 6px，前爪垂进约 27px。尾巴尖本身向上翘，尖端下面仍有一点灰，那是卷起来的尾巴，不是缝。纸的 `margin-top` 仍是桌面 108px、手机 72px，耳朵没有被视口裁掉，也没有改图。

第一张纸按三组留白，组内紧、组间松，没有改文案：

- 主诉一组：眉题上边距收到 8px、下边距 4px，导语贴在标题下 8px。
- 动作一组：红章「看演示」独自成行，章和导语之间桌面 40px、手机 28px。移除章下重复的「进入宠主端」文字链与慢加载说明，避免下方三端栏位被误读为静态只读对照表。
- 入口与凭证一组：三端栏位（`.doors`）紧接在章下面（桌面 32px、手机 24px），左列统一为带常驻 1px 下划线与 500 字重的明确动作文案（「进入宠主端」「进入医生端」「进入管理端」），右列为账号名配方向箭头 `→`（悬停/按下整行高亮且箭头右移 3px），行高 48px，既保持单张挂号单的发丝线克制感，又在静止态直接传达可点击性。底栏保留一行说明「点击上方三端入口自动填入账号与密码（Yuzhua@2026）」，移除手动复制密码按钮与重置/虚构数据说明。

第二张纸只收了小节间距：标题贴说明，截图和图说贴在标题下，端与端之间仍留一档空隙。手机宽图继续在纸内左右滑。核对图是 `deploy/demo/agent-shots/viewport-390-second-paper.png`。

## 字体、色彩、动效

字体栈与 `frontend/src/styles/main.css` 相同，不引外部字体。正文 16px / 1.7，说明 15px / 1.7。按钮高 48px，文字链至少 44px。挂号单用直角和 1px `#222` 外框，无投影。这和产品界面的 16px 圆角不同：纸是演示页自己的物件，截图仍是产品界面。

进入时纸上移 8px，180ms。往下滚时，宠主首页在视口里由遮罩揭开，缩放从 1.12 回到 1（CSS `animation-timeline: view()`）。其余区块滚入时上移 12px，只播一次。`prefers-reduced-motion` 时全部直接到位。没有引入 GSAP：成稿必须是单文件、无 CDN，滚动叙事用平台的 scroll-timeline，不另放库文件。
