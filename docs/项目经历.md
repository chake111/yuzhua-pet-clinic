# 愈爪｜宠物医院预约与在线问诊平台

角色：独立全栈开发｜技术栈：Vue 3、Vite、Pinia、Element Plus、Spring Boot 3、MyBatis-Plus、MySQL 8、WebSocket、Nginx、Docker

- 构建单工程双端宠物医院预约与问诊平台，前端承载移动端宠主端与按角色裁剪菜单的医管后台，后端结合 JWT 令牌版本即时失效、角色拦截与资源归属校验，保障三端权限与行级数据隔离。
- 优化首屏冷启动性能，通过组件按需拆包与首屏剥离组件库及 Axios，将入口 JS 与 CSS 的 gzip 体积由 468 KB 降至 75.5 KB，并配合 Nginx 静态预压缩、分层缓存与包体预算门禁保障弱网交付。
- 解决高并发抢号超卖与重复下单，结合排班行锁、条件 UPDATE、幂等键唯一索引与数据库租约互斥释放未支付超时号源，经 k6 100 并发抢 20 号源压测验证零超卖，Testcontainers 并发集成测试覆盖幂等防重。
- 实现基于原生 WebSocket 的图文问诊通信，协同前端会话状态与断线重连拉取历史消息，配合握手鉴权、落库 ACK 确认与已读同步确保消息落库与状态一致，支持就诊建议卡片直达挂号。
- 搭建 GitHub Actions、Testcontainers 与 Docker Compose 自动化测试与容器校验流水线，接入 Actuator、Prometheus 与慢 SQL 拦截器观测接口耗时与慢查询，支撑核心链路持续回归。
